# Contributing Guidelines

Thank you for your interest in contributing to Automation in Data Analytics.

## Getting Started

1. Fork the repository.
2. Create a feature branch.
3. Set up backend and frontend using the root README.
4. Make focused changes and test locally.
5. Open a pull request with clear context.

## Contribution Rules

- Keep changes scoped and easy to review.
- Follow existing code style and naming patterns.
- Update documentation when behavior/configuration changes.
- Avoid committing secrets or local environment files.

## Local Validation Checklist

- Backend starts successfully.
- Frontend loads and can call backend.
- CSV analysis flow works with sample data (`titanic.csv`).

## Pull Request Expectations

- Describe what changed and why.
- List manual/automated validation performed.
- Include screenshots for UI changes when relevant.

## Reporting Bugs

Include:
- environment (OS, Python version, browser),
- reproducible steps,
- expected vs actual behavior,
- logs/error messages.
